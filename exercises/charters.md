# ภารกิจการทดสอบเชิงสำรวจ (Exploratory Testing Charters)

ภารกิจแต่ละข้อใช้เวลาประมาณ 30 ถึง 45 นาที เป็นการกำหนดทิศทางการสำรวจ ไม่ได้บอกว่าต้องพบอะไร ผู้ทดสอบเป็นผู้วางแผนเองว่าจะทดสอบอะไร อย่างไร และด้วยข้อมูลใด และตัดสินความถูกต้องจากเอกสารเท่านั้น

รูปแบบ: **สำรวจ** [พื้นที่] **ด้วย** [เครื่องมือหรือข้อมูล] **เพื่อค้นหา** [ข้อมูลหรือความเสี่ยง]

## รายการภารกิจ

| # | ภารกิจ | เอกสารที่ใช้ |
|---|---|---|
| 1 | สำรวจการคำนวณราคาของตะกร้าและคำสั่งซื้อ ด้วยการเลือกสินค้า จำนวน และคูปองที่หลากหลาย เพื่อค้นหาความไม่สอดคล้องกับข้อกำหนดด้านราคา | `PRD-CART`, `PRD-COUPON`, `PRD-CROSS`, `glossary` |
| 2 | สำรวจสิ่งที่ผู้ใช้แต่ละบทบาททำได้และทำไม่ได้ ทั้งผ่านหน้าจอและผ่าน API เพื่อค้นหาการเข้าถึงที่ไม่ตรงกับตารางสิทธิ์ | `rbac-matrix`, `PRD-COMMON`, `PRD-AUTH` |
| 3 | สำรวจวงจรชีวิตของคำสั่งซื้อ ตั้งแต่สร้างจนถึงคืนสินค้า ด้วยหลายบทบาท เพื่อค้นหาการเปลี่ยนสถานะและผลข้างเคียงที่ไม่ตรงกับข้อกำหนด | `PRD-ORDER`, `state-machines` |
| 4 | สำรวจสต็อกสินค้าเมื่อมีหลายการกระทำต่อสินค้าเดียวกัน (สั่งซื้อ ยกเลิก คืน ปรับสต็อก และคำขอพร้อมกัน) เพื่อค้นหาความไม่สอดคล้องของจำนวนและประวัติ | `PRD-INVENTORY`, `PRD-ORDER`, `PRD-CROSS` |
| 5 | สำรวจบัญชีและเซสชัน (สมัคร เข้าสู่ระบบ ล็อก ออกจากระบบ เปลี่ยนรหัสผ่าน) เพื่อค้นหาพฤติกรรมที่ไม่ตรงกับข้อกำหนด | `PRD-AUTH`, `PRD-ADMIN` |
| 6 | สำรวจการตรวจสอบข้อมูลนำเข้าของฟอร์มและ API ด้วยข้อมูลผิดรูปแบบหลายแบบ เพื่อค้นหาช่องว่างระหว่างหน้าจอ API และข้อกำหนด | `PRD-COMMON`, `api` |
| 7 | สำรวจการค้นหา กรอง เรียง และแบ่งหน้าของรายการสินค้า คำสั่งซื้อ และผู้ใช้ เพื่อค้นหาผลลัพธ์ที่ไม่ตรงกับเงื่อนไขที่เลือก | `PRD-CATALOG`, `PRD-ORDER`, `PRD-ADMIN`, `PRD-COMMON` |
| 8 | สำรวจรายงานและงานตั้งเวลา ด้วยการสร้างคำสั่งซื้อหลายสถานะและหลายช่วงเวลา เพื่อค้นหาตัวเลขที่ไม่สอดคล้องกับข้อมูลต้นทาง | `PRD-REPORT`, `PRD-SCHEDULE`, `jobs` |
| 9 | สำรวจส่วนติดต่อผู้ใช้ที่ความกว้างหน้าจอต่าง ๆ และด้วยแป้นพิมพ์ เพื่อค้นหาข้อความ การจัดวาง และการเข้าถึงที่ไม่ตรงกับแนวทาง | `copy-deck`, `ui-guidelines`, `wireframes` |
| 10 | สำรวจรีวิว รายการโปรด และข้อมูลที่ผู้ใช้ป้อนซึ่งแสดงผลกลับบนหน้าจอ เพื่อค้นหาความไม่สอดคล้องของกฎและการแสดงผล | `PRD-REVIEW`, `PRD-WISHLIST`, `PRD-COMMON` |

## คำแนะนำการสำรวจ

1. อ่านเอกสารที่เกี่ยวข้องก่อน แล้วจดสิ่งที่ข้อกำหนดบังคับเป็นรายการ
2. วางแผนอย่างคร่าว ๆ ว่าจะทดสอบด้วยข้อมูลใดบ้าง และเริ่มจากข้อมูลเริ่มต้นเสมอ
3. บันทึกสิ่งที่ทำระหว่างสำรวจ เพื่อให้ผู้อื่นทำซ้ำได้
4. เมื่อพบสิ่งผิดปกติ ตรวจกับเอกสารก่อนว่าผิดจริงหรือไม่ และหาว่าเกิดได้จากทางอื่นหรือไม่ (เช่น ผ่านหน้าจอ ผ่าน API)
5. จบภารกิจด้วยการสรุป: ทดสอบอะไรไปแล้ว พบอะไร และมีอะไรที่ยังไม่ได้ทดสอบ
