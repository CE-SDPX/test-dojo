# แบบฟอร์มออกแบบการทดสอบ (Test Design)

ใช้บันทึกการวิเคราะห์ก่อนลงมือทดสอบ แบบฟอร์มนี้เน้นเหตุผลของการเลือกค่าทดสอบ ไม่ใช่เพียงรายการค่าที่ใช้

## 1. ข้อมูลทั่วไป

| รายการ | ข้อมูล |
|---|---|
| กลุ่ม / ผู้จัดทำ | |

| รหัสแฮชซอร์ส (`source_hash`) | |
