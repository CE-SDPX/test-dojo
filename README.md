# DojoMart (test-dojo)

DojoMart เป็นระบบร้านค้าออนไลน์ขนาดเล็กที่สร้างขึ้นเพื่อใช้ฝึกทดสอบซอฟต์แวร์ ระบบมีส่วนหน้าเว็บ ส่วนบริการ API ฐานข้อมูล และงานตั้งเวลา ทำงานในคอนเทนเนอร์บนเครื่องของผู้ทดสอบเอง ผู้ทดสอบใช้เอกสารข้อกำหนดและเอกสารออกแบบเป็นเกณฑ์ตัดสินว่าพฤติกรรมของระบบถูกต้องหรือไม่ และค้นหาข้อบกพร่องที่ระบบมีอยู่

> **สถานะของ repository:** ขณะนี้มีเอกสารข้อกำหนด เอกสารออกแบบ คำแนะนำการใช้งาน และแบบฟอร์มสำหรับผู้ทดสอบครบแล้ว ส่วนซอร์สโค้ดของระบบ (`app/`) และไฟล์ `docker-compose.yml` ยังอยู่ระหว่างจัดทำ คำสั่งในคู่มือเริ่มต้นใช้งานจะใช้ได้เมื่อมีซอร์สโค้ดแล้ว

## ข้อควรทราบ

- ระบบนี้มีข้อบกพร่องและจุดอ่อนด้านความปลอดภัยที่ตั้งใจให้มี จำนวนและตำแหน่งไม่เปิดเผย และไม่มีเฉลย
- เอกสารใน `docs/` ถูกต้องและสอดคล้องกัน เป็นเกณฑ์ตัดสินเพียงแหล่งเดียว พฤติกรรมที่ไม่ตรงกับเอกสารถือเป็นข้อบกพร่อง
- ห้ามเปิดพอร์ตของระบบให้เครื่องอื่นในเครือข่ายเข้าถึง
- ระบบรายงานและตรวจข้อบกพร่อง รวมถึงกติกาการให้คะแนน อยู่ในระบบรายงานของรายวิชา ไม่อยู่ใน repository นี้

## เริ่มต้นอย่างรวดเร็ว

```bash
git clone <URL ของ repository ที่ผู้สอนกำหนด>
cd test-dojo
git checkout <แท็กเวอร์ชันที่ผู้สอนกำหนด>
docker compose up --build
```

จากนั้นเปิด `http://localhost:8000` (หน้าเว็บ) และ `http://localhost:8001` (API)

| บทบาท | Username | รหัสผ่าน |
|---|---|---|
| customer | `customer1`, `customer2`, `customer3` | `Customer123` |
| staff | `staff1`, `staff2`, `staff3` | `Staff123` |
| manager | `manager1`, `manager2`, `manager3` | `Manager123` |
| admin | `admin1`, `admin2`, `admin3` | `Admin123` |

ล้างข้อมูลกลับสู่ข้อมูลเริ่มต้น

```bash
curl -X POST http://localhost:8001/api/reset
```

รายละเอียดทั้งหมดอยู่ใน `docs/instructions/getting-started.md`

## ฟีเจอร์ของระบบโดยสรุป

| กลุ่ม | ฟีเจอร์ |
|---|---|
| ลูกค้า (`customer`) | สมัครสมาชิก เข้าสู่ระบบ ค้นหาและเรียกดูสินค้า รายการโปรด รีวิว ตะกร้า คูปอง สั่งซื้อ ชำระเงิน (จำลอง) ยกเลิกและคืนสินค้า จัดการโปรไฟล์และที่อยู่ |
| เจ้าหน้าที่ (`staff`) | จัดการคิวคำสั่งซื้อ ปรับสต็อก ดูสินค้าใกล้หมด |
| ผู้จัดการ (`manager`) | จัดการสินค้าและคูปอง ดูรายงานยอดขายและส่งออก CSV |
| ผู้ดูแลระบบ (`admin`) | ทำได้ทุกอย่างของ staff และ manager จัดการผู้ใช้ และงานตั้งเวลาทุกชั่วโมง |
