# PRD-CART: ตะกร้าสินค้าและการคำนวณราคา

## 1. ภาพรวม

ลูกค้าเพิ่มสินค้าลงตะกร้า ปรับจำนวน และดูสรุปราคาซึ่งประกอบด้วยส่วนลดตามยอด ส่วนลดคูปอง ภาษีมูลค่าเพิ่ม และค่าจัดส่ง ลำดับการคำนวณกำหนดไว้ใน `PRD-CROSS` (`REQ-CROSS-001`)

## 2. ขอบเขต

**อยู่ในขอบเขต:** การเพิ่ม แก้ไข ลบรายการในตะกร้า การคงอยู่ของตะกร้า การคำนวณราคา และการแสดงตะกร้า

**อยู่นอกขอบเขต:** การแชร์ตะกร้า ตะกร้าของผู้ที่ยังไม่เข้าสู่ระบบ และการบันทึกตะกร้าไว้ซื้อภายหลัง

## 3. ข้อกำหนด

เฉพาะบทบาท `customer` ใช้ endpoint ของตะกร้าได้ บทบาทอื่นได้ 403 `FORBIDDEN`

### REQ-CART-001: การเพิ่มสินค้าลงตะกร้า

`POST /api/cart/items` รับ `product_id` และ `quantity` ตอบ 200 พร้อมตะกร้าทั้งใบหลังการเพิ่ม

- สินค้าต้องมีอยู่และ `active = true` มิฉะนั้นตอบ 404 `NOT_FOUND`
- `quantity` เป็นจำนวนเต็ม 1 ถึง 10 มิฉะนั้นตอบ 400 `VALIDATION_ERROR`
- หากสินค้านั้นอยู่ในตะกร้าแล้ว ให้รวมเข้ากับรายการเดิม (ไม่สร้างรายการซ้ำ) และจำนวนรวมหลังการเพิ่มต้องไม่เกิน 10 มิฉะนั้นตอบ 409 `QUANTITY_LIMIT`
- จำนวนรวมหลังการเพิ่มต้องไม่เกินสต็อกปัจจุบัน มิฉะนั้นตอบ 409 `INSUFFICIENT_STOCK` (ข้อความ `This product is out of stock.` เมื่อสต็อกเป็น 0 หรือ `Only {n} left in stock.` เมื่อสต็อกเหลือ n)
- ตะกร้ามีรายการสินค้าต่างชนิดได้ไม่เกิน 20 รายการ การเพิ่มสินค้าชนิดที่ 21 ตอบ 409 `CART_LINE_LIMIT`
- ลำดับการตรวจ: 404 → 400 → `QUANTITY_LIMIT` → `INSUFFICIENT_STOCK` → `CART_LINE_LIMIT`

**เกณฑ์การตรวจรับ**

| ID | Given | When | Then |
|---|---|---|---|
| AC-CART-001.1 | ตะกร้าของ `customer1` ว่าง | เพิ่ม Ceramic Coffee Mug จำนวน 2 | ตะกร้ามี 1 รายการ จำนวน 2 |
| AC-CART-001.2 | ตะกร้ามี Ceramic Coffee Mug จำนวน 2 | เพิ่ม Ceramic Coffee Mug อีก 3 | ตะกร้ายังมี 1 รายการ จำนวนเป็น 5 |
| AC-CART-001.3 | ไม่มี | เพิ่มสินค้าที่ `quantity` เป็น 0 | ได้ 400 `VALIDATION_ERROR` |
| AC-CART-001.4 | สินค้า Vintage Poster สต็อกเป็น 0 | เพิ่มลงตะกร้า | ได้ 409 `INSUFFICIENT_STOCK` ข้อความ `This product is out of stock.` |

### REQ-CART-002: การแก้ไขจำนวน

`PATCH /api/cart/items/{item_id}` รับ `quantity` ตอบ 200 พร้อมตะกร้าทั้งใบ

- `quantity` เป็นจำนวนเต็ม 1 ถึง 10 มิฉะนั้นตอบ 400 `VALIDATION_ERROR`
- จำนวนใหม่ต้องไม่เกินสต็อกปัจจุบัน มิฉะนั้นตอบ 409 `INSUFFICIENT_STOCK`
- `item_id` ต้องเป็นรายการในตะกร้าของผู้เรียก มิฉะนั้นตอบ 404 `NOT_FOUND`
- การแก้ไขจำนวนเป็นการตั้งค่าใหม่ (ไม่ใช่การบวกเพิ่ม)

### REQ-CART-003: การลบรายการ

`DELETE /api/cart/items/{item_id}` ตอบ 200 พร้อมตะกร้าทั้งใบหลังลบ `item_id` ต้องเป็นรายการในตะกร้าของผู้เรียก มิฉะนั้นตอบ 404 `NOT_FOUND`

**เกณฑ์การตรวจรับ**

| ID | Given | When | Then |
|---|---|---|---|
| AC-CART-003.1 | `customer1` ล็อกอินอยู่ และรายการตะกร้ารหัส X เป็นของ `customer3` | `customer1` เรียก `DELETE /api/cart/items/X` | ได้ 404 และตะกร้าของ `customer3` ไม่เปลี่ยนแปลง |

### REQ-CART-004: ความเป็นเจ้าของและการคงอยู่ของตะกร้า

- ลูกค้าแต่ละคนมีตะกร้า 1 ใบเป็นของตนเอง
- ตะกร้าต้องคงอยู่เมื่อออกจากระบบและเข้าสู่ระบบใหม่ รวมถึงข้ามเบราว์เซอร์หรืออุปกรณ์
- ตะกร้าถูกล้างเมื่อสร้างคำสั่งซื้อสำเร็จเท่านั้น (นอกเหนือจากการลบรายการโดยลูกค้า และการนำสินค้าที่ถูกปิดการใช้งานออกตาม `REQ-CAT-009`)

### REQ-CART-005: ยอดรวมรายการและยอดรวมก่อนลด

- `line_total` เท่ากับราคาต่อหน่วยปัจจุบัน × จำนวน
- `subtotal` เท่ากับผลรวมของ `line_total` ทุกรายการ
- ตะกร้าว่างมีจำนวนเงินทุกรายการเป็น `0.00` (รวมค่าจัดส่ง)

### REQ-CART-006: ส่วนลดตามยอด

- หาก `subtotal` ตั้งแต่ 1,000.00 บาทขึ้นไป ระบบให้ส่วนลด 10% ของ `subtotal` ปัดเศษ half-up เป็น 2 ตำแหน่ง
- หาก `subtotal` ต่ำกว่า 1,000.00 บาท ส่วนลดตามยอดเป็น 0.00
- ตัวอย่าง: subtotal 2,000.00 → ส่วนลด 200.00, subtotal 1,708.00 → ส่วนลด 170.80

**เกณฑ์การตรวจรับ**

| ID | Given | When | Then |
|---|---|---|---|
| AC-CART-006.1 | ตะกร้ามี Rain Jacket ×1 (1,590.00) | ดูสรุปราคา | ส่วนลดตามยอดเป็น 159.00 |
| AC-CART-006.2 | ตะกร้ามี Wireless Mouse ×1 (599.00) | ดูสรุปราคา | ส่วนลดตามยอดเป็น 0.00 |

### REQ-CART-007: ภาษีมูลค่าเพิ่ม (VAT)

- VAT เท่ากับ 7% ของยอดสินค้า (goods total) ปัดเศษ half-up เป็น 2 ตำแหน่ง
- VAT ไม่ถูกคิดจากค่าจัดส่ง
- ตัวอย่าง: ยอดสินค้า 1,800.00 → VAT 126.00, ยอดสินค้า 71.50 → VAT 5.01, ยอดสินค้า 0.00 → VAT 0.00

**เกณฑ์การตรวจรับ**

| ID | Given | When | Then |
|---|---|---|---|
| AC-CART-007.1 | ตะกร้ามี Sticky Notes Pack ×4 (รวม 100.00) ไม่ใช้คูปอง | ดูสรุปราคา | VAT เป็น 7.00 |
| AC-CART-007.2 | ตะกร้ามี Running Socks (3 pairs) ×1 (71.50) | ดูสรุปราคา | VAT เป็น 5.01 |

### REQ-CART-008: ค่าจัดส่ง

- หากยอดสินค้า (goods total) ตั้งแต่ 500.00 บาทขึ้นไป ค่าจัดส่งเป็น 0.00 (ส่งฟรี)
- หากยอดสินค้าต่ำกว่า 500.00 บาท (รวมกรณีที่เป็น 0.00 เพราะส่วนลด) ค่าจัดส่งเป็น 50.00 บาท
- ยกเว้นตะกร้าว่างซึ่งค่าจัดส่งเป็น 0.00
- การพิจารณาใช้ยอดสินค้าหลังหักส่วนลดทั้งสองประเภทแล้ว

**เกณฑ์การตรวจรับ**

| ID | Given | When | Then |
|---|---|---|---|
| AC-CART-008.1 | ตะกร้ามี Sticky Notes Pack ×4 (100.00) | ดูสรุปราคา | ค่าจัดส่งเป็น 50.00 |
| AC-CART-008.2 | ตะกร้ามี Wireless Mouse ×1 (599.00) | ดูสรุปราคา | ค่าจัดส่งเป็น 0.00 |

### REQ-CART-009: ยอดชำระสุทธิ

- ยอดชำระสุทธิ = ยอดสินค้า + VAT + ค่าจัดส่ง
- ทุกจำนวนเงินที่ API ส่งออกเป็นสตริงทศนิยม 2 ตำแหน่ง และผลรวมที่แสดงต้องสอดคล้องกับส่วนประกอบเสมอ
- ตัวอย่างครบวงจรอยู่ใน `REQ-CROSS-002`

### REQ-CART-010: รูปแบบการตอบกลับของตะกร้า

`GET /api/cart` และทุก endpoint ของตะกร้าที่ตอบตะกร้า มีโครงสร้างดังนี้

```json
{
  "items": [
    { "id": 12, "product_id": 1, "sku": "DM-1001", "name": "Ceramic Coffee Mug",
      "unit_price": "129.00", "quantity": 2, "line_total": "258.00", "stock_status": "IN_STOCK" }
  ],
  "coupon": null,
  "pricing": {
    "subtotal": "258.00", "volume_discount": "0.00", "coupon_discount": "0.00",
    "goods_total": "258.00", "vat": "18.06", "shipping": "50.00", "grand_total": "326.06"
  }
}
```

- รายการเรียงตามลำดับที่เพิ่มเข้าตะกร้า (`id` จากน้อยไปมาก)
- ฟิลด์ `coupon` กำหนดใน `REQ-COUP-004`

### REQ-CART-011: หน้าตะกร้า

- หน้า `/cart` แสดงรายการสินค้า (ชื่อ ราคาต่อหน่วย ช่องเลือกจำนวน ยอดรวมรายการ ปุ่ม Remove) ช่องใส่คูปอง และกล่องสรุปราคาที่เรียงเป็น Subtotal, Volume discount, Coupon discount, VAT (7%), Shipping, Total
- ทุกครั้งที่ลูกค้าเปลี่ยนจำนวน ลบรายการ หรือใช้/ลบคูปอง ยอดบนหน้าจอต้องเปลี่ยนทันทีโดยไม่ต้องโหลดหน้าใหม่ และตรงกับที่ API คำนวณ
- ปุ่ม Checkout ต้องปิดใช้งานเมื่อตะกร้าว่าง หน้าตะกร้าว่างแสดงข้อความ `Your cart is empty.`
- จำนวนเงินทั้งหมดบนหน้าจอใช้รูปแบบ `฿1,234.50` และจัดชิดขวาในตาราง

## 4. สมมติฐาน

- ราคาในตะกร้าไม่รวม VAT ทุกจำนวนเงินบนหน้าจอตะกร้าแสดงรายการ VAT แยกต่างหาก
