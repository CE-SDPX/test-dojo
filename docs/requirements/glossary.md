# อภิธานศัพท์และกฎกลาง

เอกสารฉบับนี้นิยามศัพท์และกฎที่ใช้ร่วมกันในทุก PRD หากถ้อยคำในเอกสารอื่นขัดแย้งกับนิยามในเอกสารนี้ ให้ถือว่าเอกสารฉบับนี้เป็นหลัก

## 1. บทบาท (Role)

| Role | ชื่อเรียก | หน้าที่โดยสรุป |
|---|---|---|
| (ไม่มีบทบาท / ไม่ได้เข้าสู่ระบบ) | ผู้เยี่ยมชม (Guest) | เรียกดู ค้นหา และดูรายละเอียดสินค้ารวมถึงรีวิวได้โดยไม่ต้องเข้าสู่ระบบ ไม่มีตะกร้า ไม่มีรายการโปรด และสั่งซื้อไม่ได้ |
| `customer` | ลูกค้า | เลือกซื้อสินค้า สั่งซื้อ จัดการโปรไฟล์และที่อยู่ของตนเอง |
| `staff` | เจ้าหน้าที่คลังและจัดส่ง | ดูและดำเนินการคำสั่งซื้อ ปรับสต็อกสินค้า |
| `manager` | ผู้จัดการสินค้าและการตลาด | จัดการสินค้า คูปอง และรายงานยอดขาย |
| `admin` | ผู้ดูแลระบบ | ดำเนินการได้ทุกหน้าที่ของ `staff` และ `manager` รวมทั้งจัดการผู้ใช้และงานตั้งเวลา (ไม่รวมหน้าซื้อสินค้าของ `customer`) |

ผู้เยี่ยมชมไม่ใช่ค่า `role` ในระบบ (ไม่มีบัญชีผู้ใช้) แต่เป็นสถานะ "ไม่ได้ส่งโทเคน" เอกสารอื่นที่เขียนว่า endpoint "ไม่ต้องยืนยันตัวตน" หมายถึงผู้เยี่ยมชมเรียกได้ด้วย

รายละเอียดสิทธิ์รายหน้าและรายจุดเชื่อมต่อ (endpoint) ปรากฏใน `docs/design/rbac-matrix.md`

## 2. ศัพท์เกี่ยวกับราคา

| ศัพท์ | นิยาม |
|---|---|
| ราคาต่อหน่วย (unit price) | ราคาของสินค้า 1 ชิ้น **ไม่รวมภาษีมูลค่าเพิ่ม (VAT)** มีทศนิยม 2 ตำแหน่ง |
| ยอดรวมรายการ (line total) | ราคาต่อหน่วย × จำนวน (ค่าที่ได้เป็นทศนิยม 2 ตำแหน่งโดยไม่ต้องปัดเศษ) |
| ยอดรวมก่อนลด (subtotal) | ผลรวมของยอดรวมรายการทุกรายการ |
| ส่วนลดตามยอด (volume discount) | ส่วนลดอัตโนมัติที่คิดจาก subtotal ตาม `REQ-CART-006` |
| ยอดหลังส่วนลดตามยอด (amount after volume discount) | subtotal − ส่วนลดตามยอด |
| ส่วนลดคูปอง (coupon discount) | ส่วนลดจากคูปองที่คิดจากยอดหลังส่วนลดตามยอด ตาม `PRD-COUPON` |
| ยอดสินค้า (goods total) | ยอดหลังส่วนลดตามยอด − ส่วนลดคูปอง |
| ภาษีมูลค่าเพิ่ม (VAT) | ภาษีที่คิดจากยอดสินค้า ตาม `REQ-CART-007` |
| ค่าจัดส่ง (shipping fee) | ค่าจัดส่งที่คิดตามยอดสินค้า ตาม `REQ-CART-008` |
| ยอดชำระสุทธิ (grand total) | ยอดสินค้า + VAT + ค่าจัดส่ง |

## 3. การปัดเศษ

- ระบบต้องปัดเศษแบบ **half-up**: เมื่อส่วนที่ถูกตัดทิ้งมีค่าตั้งแต่ครึ่งหนึ่งของหลักสุดท้ายที่เก็บขึ้นไป ให้ปัดขึ้น มิฉะนั้นให้ปัดลง
- การคำนวณต้องใช้เลขทศนิยมฐานสิบที่แม่นยำ (decimal) ไม่ใช้เลขทศนิยมฐานสอง (binary floating point)
- ตัวอย่างการปัดเป็น 2 ตำแหน่ง: 5.005 → 5.01, 2.675 → 2.68, 2.674 → 2.67, 0.125 → 0.13
- ตัวอย่างการปัดเป็น 1 ตำแหน่ง: 4.25 → 4.3, 4.24 → 4.2
- ค่าที่ต้องปัดเศษในระบบมีเพียงรายการต่อไปนี้ และต้องปัดเฉพาะที่ผลลัพธ์ของแต่ละรายการ ไม่ปัดค่าระหว่างทางอื่น: ส่วนลดตามยอด, ส่วนลดคูปองแบบเปอร์เซ็นต์, VAT, ยอดเฉลี่ยต่อออเดอร์ในรายงาน และคะแนนรีวิวเฉลี่ย

## 4. รูปแบบของจำนวนเงิน

| บริบท | รูปแบบ | ตัวอย่าง |
|---|---|---|
| API (JSON) | สตริงทศนิยม 2 ตำแหน่งเสมอ ไม่มีตัวคั่นหลักพัน | `"1234.50"`, `"0.00"` |
| หน้าจอ (UI) | สัญลักษณ์ `฿` ตัวคั่นหลักพันด้วยจุลภาค ทศนิยม 2 ตำแหน่งเสมอ | `฿1,234.50` |
| ฐานข้อมูล | จำนวนเต็มหน่วยสตางค์ | `123450` |
| CSV | ทศนิยม 2 ตำแหน่ง ใช้จุดเป็นตัวคั่นทศนิยม ไม่มีสัญลักษณ์สกุลเงิน | `1234.50` |

## 5. เวลาและวันที่

- เขตเวลาของระบบคือ **Asia/Bangkok (UTC+07:00)** การกำหนด "วันที่" และ "ชั่วโมง" ในทุกที่ใช้เขตเวลานี้
- เวลาที่ API ส่งออกอยู่ในรูป ISO 8601 พร้อมส่วนต่างเวลา เช่น `2026-10-10T14:30:05+07:00` (มีวินาที) ยกเว้นเวลาของคูปองซึ่งละเอียดระดับนาทีและไม่มีวินาที เช่น `2026-10-10T14:30+07:00`
- วันที่ล้วนใช้รูปแบบ `YYYY-MM-DD`
- การแสดงผลบนหน้าจอใช้รูปแบบ `dd/MM/yyyy HH:mm` (24 ชั่วโมง) และ `dd/MM/yyyy` สำหรับวันที่ล้วน
- สัญกรณ์ช่วง: `[a, b)` หมายถึงรวม a และไม่รวม b, `[a, b]` หมายถึงรวมทั้งสองค่า
- "ละเอียดระดับนาที" หมายถึงระบบเปรียบเทียบโดยอ้างอิงนาทีที่ระบุ (ตัดวินาทีและเศษวินาทีของเวลาปัจจุบันตามบริบทที่ระบุในแต่ละข้อกำหนด)

## 6. สถานะ

| ประเภท | ค่า |
|---|---|
| สถานะคำสั่งซื้อ | `PENDING_PAYMENT`, `PAID`, `PACKED`, `SHIPPED`, `DELIVERED`, `CANCELLED`, `RETURNED` |
| สถานะบัญชีผู้ใช้ | `ACTIVE`, `LOCKED` (ล็อกโดยผู้ดูแลระบบ) นอกจากนี้บัญชีอาจถูก "ล็อกชั่วคราว" จากการเข้าสู่ระบบผิดซ้ำ ซึ่งไม่ใช่ค่า `LOCKED` |
| สถานะคูปอง (คำนวณจากข้อมูล) | `DISABLED`, `SCHEDULED`, `ACTIVE`, `EXPIRED` |
| สถานะการรันงาน | `RUNNING`, `SUCCESS`, `FAILED` |

คำอธิบายการเปลี่ยนสถานะอยู่ใน `docs/design/state-machines.md`

## 7. ศัพท์ที่ต้องใช้ให้สม่ำเสมอบนหน้าจอ

| ใช้ | ไม่ใช้ |
|---|---|
| Cart | Basket, Bag |
| Order | Purchase |
| Sign in / Sign out | Login / Logout (ใช้เฉพาะในชื่อไฟล์และชื่อ API) |
| Coupon | Voucher, Promo code |
| Shipping | Delivery fee |
| Total | Amount due (ใช้เฉพาะตามที่ระบุใน copy-deck) |

รายการข้อความทั้งหมดบนหน้าจอระบุไว้ใน `docs/design/ui/copy-deck.md`

## 8. คำย่อ

| คำย่อ | ความหมาย |
|---|---|
| PRD | Product Requirements Document เอกสารข้อกำหนดผลิตภัณฑ์ |
| REQ | Requirement ข้อกำหนด รหัสรูปแบบ `REQ-<ฟีเจอร์>-<เลขลำดับ>` |
| AC | Acceptance Criteria เกณฑ์การตรวจรับ รหัสรูปแบบ `AC-<ฟีเจอร์>-<เลข REQ>.<ลำดับ>` |
| RBAC | Role-Based Access Control การควบคุมสิทธิ์ตามบทบาท |
| API | Application Programming Interface |
