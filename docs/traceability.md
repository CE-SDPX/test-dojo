# ตารางสืบย้อน (Traceability Matrix)

ตารางนี้เชื่อมข้อกำหนด (REQ) กับเกณฑ์การตรวจรับ (AC) เอกสารออกแบบ หน้าจอ และ endpoint ที่เกี่ยวข้อง คอลัมน์ "กรณีทดสอบ" เว้นว่างไว้ให้ผู้ทดสอบกรอกรหัสกรณีทดสอบของตนเอง เพื่อตรวจว่าข้อกำหนดใดยังไม่มีกรณีทดสอบครอบคลุม

ตารางนี้สร้างจาก PRD ใน `docs/requirements/` หากข้อกำหนดเปลี่ยน ต้องปรับตารางให้ตรงกัน

สรุป: ข้อกำหนด 120 ข้อ เกณฑ์การตรวจรับ 132 ข้อ
