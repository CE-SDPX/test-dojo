# โครงหน้าจอ (Wireframes)

เอกสารนี้ระบุโครงสร้างและลำดับองค์ประกอบของแต่ละหน้า ข้อความจริงใช้ตาม `copy-deck.md` และกฎการจัดวางตาม `ui-guidelines.md`

## 1. โครงร่วมของทุกหน้า

```
+----------------------------------------------------------------+
| DojoMart   [เมนูตามบทบาท ...]   [ช่องค้นหา*]   Signed in as X  |  <- header สูง 56 px
+----------------------------------------------------------------+
|                                                                |
|   เนื้อหาของหน้า (หัวข้อ h1 ก่อนเสมอ)                          |
|                                                                |
+----------------------------------------------------------------+
| DojoMart v1.0.0 (a1b2c3d4)                                     |  <- footer
+----------------------------------------------------------------+
* ช่องค้นหาแสดงเฉพาะบทบาท customer
```

- หน้าจอกว้างน้อยกว่า 768 px: เมนูยุบเป็นปุ่ม `Menu` ที่เปิดรายการเมนูแนวตั้ง และช่องค้นหาย้ายลงเป็นแถวใหม่ใต้แถบหัว
- หน้า Sign in และ Create an account ไม่มีเมนูและช่องค้นหา แสดงเฉพาะชื่อระบบ


ลำดับองค์ประกอบในการ์ด: รูป, ชื่อสินค้า (เป็นลิงก์ไปรายละเอียด), ราคา, คะแนน, สถานะสต็อก, ปุ่ม Add to cart

## 3. หน้ารายละเอียดสินค้า (`/products/{id}`)

ลำดับองค์ประกอบ

1. ลิงก์ `Back to products`
2. รูปสินค้า (ซ้าย) และข้อมูลหลัก (ขวา): ชื่อ (`h1`), หมวดหมู่, ราคา, คะแนน, สถานะสต็อก, ช่อง `Quantity` (1 ถึง 10), ปุ่ม `Add to cart`, ปุ่มรายการโปรด
3. หัวข้อ `Description` และคำอธิบาย
4. หัวข้อ `Reviews` พร้อมแบบฟอร์ม `Write a review` และรายการรีวิว

จอแคบ: รูปอยู่เหนือข้อมูลหลัก

## 4. หน้า Cart (`/cart`)

```
Cart
+------------------------------------------------------------+
| Product          Unit price   Quantity      Total          |
| Ceramic Coffee   ฿129.00      [2 v]        ฿258.00 [Remove]|
| Mug                                                        |
+------------------------------------------------------------+
Coupon code [________] [Apply]            +-------------------------+
Coupon SAVE10 applied. [Remove coupon]    | Subtotal       ฿258.00  |
                                          | Volume discount  ฿0.00  |
                                          | Coupon discount  ฿0.00  |
                                          | VAT (7%)        ฿18.06  |
                                          | Shipping        ฿50.00  |
                                          | Total          ฿326.06  |

                                          +-------------------------+
```

- คอลัมน์จำนวนเงินจัดชิดขวา แถว Total ใช้ตัวหนา
- จอแคบ: กล่องสรุปราคาอยู่ใต้ตารางรายการ และตารางเลื่อนแนวนอนภายในกรอบหากจำเป็น

## 5. หน้า Checkout (`/checkout`)

1. หัวข้อ `Checkout`
2. ส่วน `Delivery address`: ปุ่มวิทยุเลือกที่อยู่ (ที่อยู่หลักถูกเลือกไว้) แต่ละรายการแสดง ป้ายกำกับ ผู้รับ เบอร์โทร และที่อยู่ หากไม่มีที่อยู่ให้แสดงข้อความและลิงก์ตาม copy-deck
3. ส่วน `Order summary`: รายการสินค้าและกล่องสรุปราคา (เหมือน Cart)
4. ปุ่ม `Place order`

## 6. หน้า Order confirmation, My orders, Order detail

- **Order confirmation:** หัวข้อ ข้อความหมายเลขคำสั่งซื้อ ยอดที่ต้องชำระ คำเตือนการยกเลิกอัตโนมัติ ตัวเลือกวิธีชำระเงิน ปุ่ม `Pay now` (แสดงเมื่อสถานะ `PENDING_PAYMENT`) ลิงก์ไป `My orders`
- **My orders:** ตัวกรอง `Status` ตารางคำสั่งซื้อ (ใหม่ไปเก่า) การแบ่งหน้า
- **Order detail:** ป้ายสถานะ, ส่วน `Items`, `Delivery address`, `Payment summary` (รวมส่วนลดคูปองและ VAT), `Timeline` (เวลาของแต่ละสถานะที่เกิดขึ้นแล้ว), `Refund amount` (เมื่อมี), `Return by` (เมื่อสถานะ `DELIVERED`), และปุ่มดำเนินการตามสถานะ

## 7. หน้า Wishlist (`/wishlist`)

รายการสินค้าเรียงจากที่เพิ่มล่าสุด แต่ละรายการมี ชื่อ ราคา สถานะสต็อก ปุ่ม `Add to cart` และ `Remove`

## 8. หน้า Profile และ Change password

- **Profile:** ส่วน Profile (ฟอร์มข้อมูลและปุ่ม `Save changes` ลิงก์ `Change password`) ตามด้วยส่วน `Addresses` (เฉพาะลูกค้า) ที่แสดงรายการที่อยู่เป็นการ์ด ป้าย `Default` และปุ่ม `Edit`, `Delete`, `Set as default` ปุ่ม `Add address` อยู่ท้ายส่วน และฟอร์มที่อยู่เปิดเป็นหน้าต่าง
- **Change password:** ฟอร์ม 3 ช่องและปุ่ม `Change password` หากอยู่ในสถานะถูกบังคับเปลี่ยนรหัสผ่านให้แสดงข้อความบังคับเหนือฟอร์ม และไม่แสดงเมนูอื่น

## 9. หน้าของ staff

- **Orders (`/staff/orders`):** แถวเครื่องมือ (ช่องค้นหา ตัวกรอง `Status`) ตารางคำสั่งซื้อ คอลัมน์ `Actions` แสดงปุ่มถัดไปตามสถานะ: `PAID` → `Mark as packed` และ `Cancel order`, `PACKED` → `Mark as shipped` และ `Cancel order`, `SHIPPED` → `Mark as delivered`, `PENDING_PAYMENT` → `Cancel order`, สถานะอื่นไม่มีปุ่ม
- **Inventory (`/staff/inventory`):** ช่องค้นหา ตารางสต็อก ปุ่ม `Adjust stock` และ `History` ต่อแถว
- **Low stock (`/staff/low-stock`):** ข้อความเวลาของ snapshot และตารางสินค้า

## 10. หน้าของ manager

- **Manage products (`/manager/products`):** ช่องค้นหา ปุ่ม `Add product` ตารางสินค้าและปุ่ม `Edit`, `Deactivate`/`Activate` ฟอร์มสินค้าเปิดเป็นหน้าต่าง
- **Coupons (`/manager/coupons`):** ช่องค้นหา ปุ่ม `Add coupon` ตารางคูปองและปุ่ม `Edit`, `Disable`/`Enable` ฟอร์มคูปองเปิดเป็นหน้าต่าง ช่อง `Percent off` และ `Maximum discount (optional)` แสดงเฉพาะเมื่อเลือก `Percentage` และช่อง `Amount off` แสดงเฉพาะเมื่อเลือก `Fixed amount` ใต้ช่อง `Starts at` และ `Expires at` มีข้อความเขตเวลา
- **Reports (`/manager/reports`):** แท็บ 4 แท็บ แต่ละแท็บมีช่องเลือกวันที่ ปุ่ม `Show report` และ `Export CSV` (ยกเว้นแท็บ Coupons) ตามด้วยผลรายงาน

## 11. หน้าของ admin

- **Users (`/admin/users`):** ช่องค้นหา ตัวกรอง `Role` ตารางผู้ใช้ ปุ่มต่อแถวตามสถานะ (`Lock` เมื่อไม่ถูกล็อก, `Unlock` เมื่อถูกล็อกหรือล็อกชั่วคราว) และ `Reset password`, `Change role` การแบ่งหน้าอยู่ด้านล่าง
- **Jobs (`/admin/jobs`):** ตารางงาน 3 แถว ปุ่ม `Run now`, `View history` ต่อแถว ผลการรันแสดงเป็นแถบแจ้ง ประวัติการรันแสดงเป็นหน้าต่างหรือส่วนใต้ตาราง

## 12. หน้า 403 และ 404

หัวข้อ ข้อความ และลิงก์ `Go to my home page` อยู่กึ่งกลางหน้า มีเมนูตามบทบาทของผู้ใช้ที่เข้าสู่ระบบแล้ว
